# genpark-screen-context

Background screen and meeting context observer.

Stop paying for closed SaaS apps. This is a terminal-native, open-source alternative to **Littlebird**.

Using native OS screenshot tools (like screencapture on Mac) on a cron loop, this skill quietly builds a rolling visual context of your screen, letting your agent understand what you are working on before you even type a prompt.

## Usage
```bash
openclaw use genpark-screen-context
```
